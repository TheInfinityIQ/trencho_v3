# T3-SPR-034 — Model-bound modular Soldier presentation

The reusable `soldier_visual.gd` reads actual `soldier.gd` instances. Its host advances simulation and then calls `sample(delta, context)`; the visual never advances a Soldier or writes model fields. It holds a weak reference and hides when the model expires or leaves the battlefield. `soldier_art.gd` lazily shares immutable metadata/textures, while each visual owns its own clock and layer nodes. No manager, autoload or simulation/save schema was added. Normal campaign/Operations code and the committed main scene remain unchanged; this is the provisional component for later presentation work.

## Transform and time ownership

`model_to_presentation: Transform2D` maps model positions into the host's presentation coordinates. Its basis also maps real movement or a reliable host-supplied model-space look vector. The separate `world_units_per_design_meter / 32` sets source-art scale uniformly. The visual does not assume that legacy fixture positions are meters. No accepted coordinates or speeds were converted or rebalanced.

The meter proof authors genuine Soldier instances in explicitly declared design meters, at speed 1.4, with a 32× model→world transform and 32 world units/m source presentation. Legacy proof Soldiers retain their initialized speeds (the moving example is 44.2 fixture units/s) and use a separate affine map with 2× basis and 0.3 rad rotation plus an origin offset. This maps the old fixture for display without labeling its units as physical meters.

Movement determines facing when no reliable look direction is supplied. Stationary samples retain last valid facing; initially unknown facing defaults to north. Hosts may supply a real look vector, such as the direction to an actual shot target. Presentation time is independent per instance, uses the host's elapsed delta, and freezes on zero delta. Sampling once after each simulation step avoids treating repeated positive-delta observations as additional time. Paused hosts can resample with zero delta. There is no animation callback that blocks simulation.

## Actual state mapping

| Existing model fact | Rendered clip / handling |
|---|---|
| Active FIT Soldier moving, not arrived | `standing_walk`, supplied four-frame .85 s loop |
| FIT stationary/arrived | `standing_idle`, supplied 2.5 s loop; facing retained |
| WOUNDED or STABILIZED | Neutral `standing_idle` fallback plus `UNSUPPORTED_VISUAL` diagnosis; no inferred kneeling/prone injury pose |
| Inactive without an actual death diagnosis | Neutral idle fallback plus `UNSUPPORTED_VISUAL: INACTIVE` |
| Newly observed DEAD with body present | `death_backward`, .9 s one-shot, final frame held |
| Already DEAD when bound | Final death frame immediately; no replay of a historical fall |
| DEAD with no body, off battlefield, or expired binding | Hidden |
| Real fire action supplied by host context | Keep nearest supported body pose; report `UNSUPPORTED_VISUAL: FIRE`; actual shot timing/ammunition unchanged |
| Reload hint supplied by a future truthful host | Same unsupported-pose behavior; current Soldier has no reload state, so the proof does not pretend to implement reloading |
| Non-rifle weapon identity | Preserve generic body presentation and report unsupported equipment; no claim of matching weapon art |

The model supplies no death-impact direction. `death_backward` is explicitly a generic available death fallback, with `DEATH_DIRECTION_UNAVAILABLE`; it is not a claim that damage came from a particular direction. No blast/death-direction mechanic was added. Wounded and stabilized also do not specify a posture, so the adapter does not infer one from the names of available animations.

All other supplied clips remain catalogued but unbound: `standing_sprint`, `crouch_idle`, `crouch_walk`, `prone_ready`, `prone_move`, `stand_to_crouch`, `crouch_to_stand`, `crouch_to_prone`, `prone_to_crouch`, `death_prone`, `death_forward`. Binding those requires real corresponding posture/activity/direction evidence, not a new visual-only gameplay state machine. Roles/equipment identities are exposed read-only; different role art was not commissioned or synthesized.
